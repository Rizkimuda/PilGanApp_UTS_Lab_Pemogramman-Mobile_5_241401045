## b. Informasi Aplikasi

### Nama Aplikasi
**PilGan**

### Deskripsi Singkat Aplikasi
PilGan adalah aplikasi kuis interaktif berbasis Flutter. Pengguna dapat memasukkan nama, memilih kategori topik kuis, menjawab rangkaian pertanyaan pilihan ganda, dan melihat perolehan skor akhir secara langsung. Progres dan jawaban pengguna dijamin aman (tidak hilang saat rotasi layar) berkat implementasi state management Provider.

### Fitur-Fitur yang Tersedia
- Input Nama & Validasi
- Pilihan Topik Kuis
- Kuis Pilihan Ganda Interaktif
- Indikator Progres Real-Time
- Navigasi Soal
- Perhitungan Skor Akhir
- Ulangi Kuis
- Dual-Theme
- Font Kustom
